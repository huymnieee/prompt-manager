# 나만의 프롬프트 관리 프로그램

이전 AI 과제에서 사용한 프롬프트를 제목과 카테고리로 정리하고, 검색하거나 즐겨찾기할 수 있는 Python 콘솔 프로그램입니다. AI에게 요청을 전송하는 기능은 없으며 프롬프트 문장을 관리합니다.

## 실행 방법

Python 3.10 이상이 필요합니다. 외부 라이브러리 설치는 필요 없습니다.

1. VSCode에서 이 프로젝트 폴더를 엽니다.
2. 위쪽 메뉴에서 **터미널 → 새 터미널**을 선택합니다.
3. 다음을 입력하고 Enter를 누릅니다.

```sh
python3 main.py
```

메뉴 번호를 입력한 뒤 Enter를 누릅니다. `0`을 입력하면 종료합니다. 각 기능이 끝나면 메뉴로 돌아옵니다.

## 기능

| 번호 | 기능 | 사용 방법 |
| --- | --- | --- |
| 1 | 프롬프트 추가 | 제목, 내용, 카테고리를 차례로 입력합니다. 내용은 한 줄로 입력합니다. |
| 2 | 전체 목록 | 등록된 모든 프롬프트의 번호, 제목, 카테고리를 확인합니다. |
| 3 | 카테고리별 조회 | 카테고리를 선택하여 해당 항목만 봅니다. |
| 4 | 검색 | 제목 또는 내용에 포함된 검색어를 찾습니다. 영문 대소문자를 구분하지 않습니다. |
| 5 | 상세 보기 | 프롬프트 번호를 선택하여 내용 전체를 봅니다. |
| 6 | 즐겨찾기 관리 | 번호를 선택하여 즐겨찾기를 추가하거나 해제합니다. |
| 7 | 즐겨찾기 목록 | 즐겨찾기한 프롬프트만 봅니다. |
| 8 | 프롬프트 수정 | 번호 선택 후 새 제목·내용·카테고리를 입력합니다. 즐겨찾기는 유지됩니다. |
| 9 | 프롬프트 삭제 | 번호 선택 후 `y`를 입력하면 삭제합니다. 다른 입력은 취소합니다. |
| 0 | 종료 | 프로그램을 종료합니다. |

목록, 검색 결과, 카테고리 조회, 즐겨찾기 목록의 번호는 모두 같은 프롬프트를 가리킵니다. 삭제하면 현재 목록 순서대로 번호가 다시 매겨집니다. ⭐는 즐겨찾기 표시입니다.

빈 제목·내용·검색어는 다시 입력하도록 안내합니다. 잘못된 메뉴·카테고리·프롬프트 번호를 입력해도 프로그램이 종료되지 않습니다. 입력 종료 또는 Ctrl+C 시에도 안내 후 종료합니다.

**추가·수정·삭제한 프롬프트와 즐겨찾기 변경은 실행 중에만 유지됩니다. 종료 후 다시 켜면 기본 프롬프트 4개로 시작합니다.** 이는 필수 과제의 동작입니다. 선택 보너스 중 수정·삭제 기능도 추가했습니다. JSON 저장·내보내기와 조회수·조회수 정렬 기능은 포함하지 않았습니다.

## 기본 데이터와 카테고리

기존 `main.py`에 준비된 프롬프트 4개를 그대로 사용했습니다. 이전 과제 문서를 참고하여 정리된 내용이며, AI에게 입력할 문장 자체를 저장합니다.

| 기본 프롬프트 | 카테고리 | 이전 과제 |
| --- | --- | --- |
| 다이어트 멘탈 코치 페르소나 | 페르소나 | B1-1 |
| 다이어트 고민 답변 생성 | 텍스트 생성 | B1-1 |
| Dream X 광고 씬1 생성 | 영상 생성 | B1-2 |
| Dream X 한강 버스킹 씬2 생성 | 영상 생성 | B1-2 |

사용 가능한 카테고리는 **텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타**입니다. 처음에는 이미지 생성·자동화·기타 카테고리에 기본 항목이 없으며 새 항목을 추가할 수 있습니다.

원본 과제: [B1-1](https://github.com/huymnieee/codyssey/tree/main/B1-1), [B1-2](https://github.com/huymnieee/codyssey/tree/main/B1-2), [B1-3](https://github.com/huymnieee/codyssey/tree/main/B1-3).

## 파일 구성

- `main.py`: 기본 프롬프트와 모든 프로그램 기능
- `test_main.py`: 실제 콘솔 입력·출력으로 기능을 확인하는 표준 라이브러리 테스트
- `.gitignore`: 자동 생성 파일 등 Git 기록에서 제외할 항목
- `README.md`: 프로그램 소개와 실행 방법
- `docs/쉬운설명.md`: 초보자를 위한 코드 설명
- `docs/개발기록.md`: Git 명령 사용과 브랜치 병합 기록
- `docs/제출안내.md`: 제출 자료 체크리스트
- `docs/screenshots/`: 실제 실행 화면 캡처

## 검증 방법

```sh
python3 -m unittest -v test_main
```

메뉴 반복과 종료, 빈 입력 재입력, 잘못된 카테고리·번호, 추가 후 상세 보기, 검색, 카테고리 조회, 즐겨찾기 추가·해제, 빈 목록, 재실행 시 초기화, 입력 종료, 모듈 가져오기, 수정 후 즐겨찾기 유지, 삭제 확인·취소, 중복 데이터 삭제 동작까지 14개 테스트로 확인합니다.
