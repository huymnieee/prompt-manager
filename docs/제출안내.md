# 제출 안내

## 제출할 저장소

https://github.com/huymnieee/prompt-manager

## 제출 자료

- GitHub 저장소 URL
- 개발 환경 화면: VSCode Python 확장 설치, Python 버전, Git 설정
- 프로그램 실행 화면: 메뉴, 추가, 목록, 카테고리 조회, 검색, 상세 보기, 즐겨찾기
- `git log --oneline --graph --all` 화면

실제 캡처를 `docs/screenshots/`에 보관합니다. 제출 시스템에 별도 첨부가 필요하면 이 폴더의 이미지 파일을 사용하세요.

## 요구사항 확인

| 조건 | 확인 방법 |
| --- | --- |
| Python 3.10 이상 | Python 3.11.3 확인 및 실행 |
| VSCode Python 확장 | Microsoft Python 확장 설치 화면 확인 |
| Hello 실행 | 개발 중 `print("Hello")` 실행 확인 및 기존 커밋 기록 |
| 기본 프롬프트 최소 3개 | 이전 과제에서 정리한 기존 프롬프트 4개 유지 |
| 리스트·딕셔너리 | `main.py`의 `prompts` 데이터 |
| 필수 메뉴 전체 | 메뉴 1~7과 0 실행 |
| 입력 오류 안내 | 실제 콘솔 검증 10개 통과 |
| 종료 시 초기화 | 재시작 검증 통과 |
| 외부 라이브러리 미사용 | 프로그램은 import 없이 Python 기본 문법과 내장 함수로 구현 |
| 기능별 함수 분리 | `main.py`의 함수 13개 |
| 의미 있는 커밋 10개 이상 | Git 로그에서 기능별 기록 확인 |
| 목록 기능 브랜치 개발·병합 | `codex/prompt-list`와 로컬 merge 기록 |
| Git 명령 8종 사용 | 개발기록 확인 |
| README | 소개·실행 방법·기능·카테고리 설명 포함 |

GitHub 계정의 VSCode 로그인 화면은 개인 계정 상태에 따라 제출 전에 확인하세요. 프로그램을 GitHub로 push하는 연결은 확인되었습니다. 과제 제출 사이트의 제출 버튼은 직접 누르세요.

## 스스로 사용해보기

1. `python3 main.py` 실행
2. `2` → 기본 4개 확인
3. `4` → `다이어트` 검색
4. `6` → `1` 선택
5. `7` → 즐겨찾기 확인
6. `0` → 종료

이 흐름을 한 번 직접 해보면 기본 사용법을 설명할 수 있습니다.
