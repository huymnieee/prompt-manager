# 처음 배우는 사람을 위한 설명

## 이 프로그램이 하는 일

AI에게 예전에 보냈던 지시문을 카드처럼 모아둡니다. 카드를 추가하고, 찾고, 별표를 붙일 수 있습니다. AI 연결이나 유료 API는 필요하지 않습니다.

VSCode의 아래쪽 터미널에서 `python3 main.py`를 입력하면 시작합니다. 번호를 입력하고 Enter를 누르면 됩니다.

처음에는 `2`를 눌러 프롬프트 4개를 확인해보세요. `4`를 누르고 `다이어트`를 검색하면 관련 항목을 찾습니다. `5`를 누른 뒤 번호를 입력하면 문장 전체를 봅니다. `6`에서 같은 번호를 고를 때마다 즐겨찾기가 켜지거나 꺼집니다. `7`은 별표가 붙은 항목만 보여줍니다. `0`은 종료입니다.

## 코드의 큰 구조

1. `CATEGORIES`: 카테고리 이름을 모아둔 목록입니다.
2. `prompts`: 프롬프트 카드 여러 개를 담는 목록입니다.
3. 각 함수: 추가·검색·즐겨찾기 등 각자 맡은 일을 합니다.
4. `main()`: 메뉴를 보여주고 입력한 번호에 따라 담당 함수를 부릅니다.
5. 마지막 두 줄: 이 파일을 직접 실행했을 때 프로그램을 시작합니다.

## 프롬프트 한 개를 읽는 법

```python
{
    "title": "프롬프트 제목",
    "content": "AI에게 보낼 지시문",
    "category": "텍스트 생성",
    "favorite": False
}
```

중괄호 `{}`는 정보 카드 하나입니다. 이를 **딕셔너리**라고 합니다. `title`은 제목, `content`는 내용, `category`는 분류, `favorite`는 즐겨찾기 여부입니다.

`False`는 즐겨찾기 꺼짐, `True`는 켜짐입니다. 카드 여러 개를 대괄호 `[]`에 모아놓은 것이 **리스트**입니다.

## 함수별 역할

| 함수 | 쉬운 뜻 |
| --- | --- |
| `show_menu()` | 메뉴를 보여주기 |
| `read_required()` | 빈 내용이면 다시 입력받기 |
| `choose_category()` | 카테고리 번호를 확인하기 |
| `add_prompt()` | 새 카드 추가하기 |
| `display_prompts()` | 카드 목록을 같은 형식으로 보여주기 |
| `show_list()` | 모든 카드 보기 |
| `show_by_category()` | 같은 분류의 카드만 보기 |
| `search_prompt()` | 제목과 내용에서 검색어 찾기 |
| `select_prompt()` | 카드 번호를 확인하고 선택하기 |
| `show_detail()` | 카드 내용 전체 보기 |
| `toggle_favorite()` | 즐겨찾기 켜기·끄기 |
| `show_favorites()` | 즐겨찾기 카드만 보기 |
| `main()` | 프로그램 전체 진행하기 |

## 자주 나오는 문법

- `print(...)`: 화면에 글자를 보여줍니다.
- `input(...)`: 내가 입력한 글자를 받습니다.
- `.strip()`: 입력 앞뒤에 실수로 들어간 공백을 없앱니다.
- `if / elif / else`: 조건에 따라 할 일을 고릅니다. 예를 들어 0이면 종료합니다.
- `while True`: 종료할 때까지 메뉴를 반복해서 보여줍니다.
- `break`: 반복을 끝냅니다.
- `for`: 프롬프트를 하나씩 살펴봅니다.
- `enumerate(..., start=1)`: 항목에 1부터 번호를 붙입니다.
- `append(...)`: 목록 맨 뒤에 새 항목을 넣습니다.
- `return`: 함수의 결과를 돌려주거나 함수 일을 끝냅니다.
- `try / except`: 예상한 입력 오류에 안내하고 계속 실행할 수 있게 합니다.
- `not`: 켜짐을 꺼짐으로, 꺼짐을 켜짐으로 바꿉니다.

## Git을 사용한 이유

파일 저장은 현재 코드를 저장합니다. Git 커밋은 변경한 코드와 변경 이유를 기록합니다. GitHub에 올리는 `push`는 그 기록을 인터넷 저장소로 보냅니다.

기능마다 기록을 남겨서 어떤 순서로 프로그램을 만들었는지 확인할 수 있습니다. 목록 기능은 별도 브랜치에서 만든 뒤 합쳤습니다. 브랜치는 별도의 작업 경로, 병합은 그 작업을 기본 경로에 합치는 일입니다.
