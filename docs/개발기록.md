## 명령별 사용

| 명령 | 실제 사용 |
| --- | --- |
| init | 기존 저장소에서 재초기화하여 저장소 설정 확인; 기존 이력 유지 |
| add | 기능마다 해당 파일을 선택 |
| commit | 기능마다 변경 목적을 기록 |
| push | Hello 확인 단계에서 GitHub 업로드 성공; 완성본도 업로드 |
| pull | 개발 전 최신 기록 확인 |
| checkout | 목록 기능 브랜치 생성 및 main 복귀 |
| clone | 공개 Hello-World 샘플 다운로드 및 구조·로그 확인 |
| merge | 목록 기능 브랜치를 로컬 main에 명시적으로 병합 |
